# Temporal RAG Project Memory

## Project Overview
- **Goal**: A well-made GitHub portfolio project for a resume.
- **Scope**: Indian Income Tax Rules 1962 and 2026 for Salaried Persons.
- **Approach**: Temporal RAG (Retrieval-Augmented Generation) with evals.
- **Workflow**: Collaborative, iterative, "make decisions on the go".

## Environment
- **Tooling**: `uv` for package management and virtual environment.
- **Libraries**: `pdfplumber` for PDF parsing.

## Directory Structure
- `data/raw/1962/` - Contains 1962 tax rules PDFs.
- `data/raw/2026/` - Contains 2026 tax rules PDFs.
- `src/` - Source code.
